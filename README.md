# 📦 OpenFood Models — Bibliothèque Dart Commune

Package Dart partagé contenant les modèles de données fondamentaux pour l'ensemble des applications OpenFood (Mobile, Admin, Restaurateur).

## 📄 Modèles Inclus
- `OrderModel` : Structure complète des commandes et statuts
- `RestaurantModel` : Données des établissements et comptes Stripe Connect
- `ProductModel` : Plats, suppléments et allergènes
- `AddressModel` : Coordonnées GPS et adresses de livraison
- `Promotion` : Règles et codes de réduction
- `InventoryItem` : Gestion des stocks
- `AppUser` / `UserModel` : Profils utilisateurs et rôles RBAC
- `AnalyticsEvent` : Télémétrie d'usage
